## Convenciones del proyecto
- `pnpm build` para compilar
- Componentes base registrados globalmente en `plugins/components.ts`
- Layouts usan `<RouterView />` (no `<slot />`)
- PostgREST joins posts↔profiles y comments↔profiles requieren batch profile fetch
- Counts (comments_count, likes_count) vía DB triggers (0013)
- Mood almacenado como `mood text` en posts, labels desde array `MOODS`
- Prioridades en tabla `event_priorities`, link por `priority_id`
- RLS requerido en todas las tablas; recargar schema cache de PostgREST tras cambios de columna
- Diseño editorial: serif (Cormorant Garamond `font-editorial`), paleta blush/mint/sage pastel, responsive mobile-first
